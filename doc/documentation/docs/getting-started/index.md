# Getting Started

Welcome. This section takes you from an empty project to a running app with real
ObersUI widgets on screen. It should take a few minutes.

## What you need

- Flutter 3.41 or newer, and Dart 3.11 or newer.
- An editor (VS Code, Android Studio, or whatever you like).

## The path

1. [**Installation**](installation.md) adds ObersUI to your project.
2. [**Your First App**](quick-start.md) sets up `OiApp` and renders your first screen.
3. [**Core Ideas**](core-ideas.md) explains the few conventions that make everything click. Read this one even if you skim the rest.
4. [**Structuring Your App**](project-structure.md) shows how to organize a real app around the library.

Once you are set up, head to [Core Concepts](../core-concepts/index.md) for the
architecture, or jump straight into the [Widgets catalog](../widgets/index.md) if
you prefer to learn by doing.
